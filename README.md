
# Tugas Besar Analisis Kompleksitas Algoritma
Proyek ini membandingkan dua pendekatan algoritma yaitu Iteratif dan Rekursif dalam melakukan konversi mata uang Rupiah (IDR) ke Dollar Amerika (USD). Aplikasi dibuat menggunakan Golang dan dilengkapi antarmuka web sederhana untuk melakukan input dan melihat hasil perhitungan.

Proyek ini juga menilai bagaimana kedua pendekatan melakukan operasi perulangan untuk menghasilkan nilai konversi berdasarkan sejumlah lembar uang tertentu. Analisis difokuskan pada efisiensi, kompleksitas waktu, serta perbedaan cara kerja masing-masing algoritma. Hasilnya memberikan gambaran mengenai metode mana yang lebih optimal dan sesuai digunakan dalam proses komputasi sederhana seperti konversi mata uang.

## Fitur
- Input jumlah nominal IDR
- Input jumlah lembar n
- Konversi menggunakan metode: Iteratif & Rekursif

## Tools
- **Go (Golang)** - backend & algoritma
- **HTML Template** - tampilan hasil + web
- **CSS** - styling halaman

## Instalasi
1. Clone repositori ini
 ```bash
git clone https://github.com/nississy/TUBES_AKA.git
 ```
2. Pergi ke project directory
```bash
cd konversi-mata-uang
```
3. Jalankan server
```bash
go run main.go
```
4. Buka di browser
```bash
http://localhost:8080
```
